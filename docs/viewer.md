# BMS作成ツール向けビューワー

BMZ Playerは、BMSE / iBMSC系のuBMplay互換コマンドラインを使って、編集中の譜面を
常駐ビューワーとして再生できます。BMS Maker 3、woseq、BmsONEからも同じ入口を
利用できます。

## コマンドライン

```text
bmz-player.exe -P -N12 "C:\path\to\_temp.bms"
bmz-player.exe -S
```

- `-P` / `--viewer-play`: 指定譜面を外部ビューワーモードで開きます。
- `-N<N>` / `-N <N>` / `--start-measure <N>`: 元譜面の0始まりの小節番号から
  再生します。BMSの先頭ノーツ余白をBMZが追加した場合も、元譜面の小節番号を指定します。
- `-S` / `--viewer-stop`: 実行中の外部ビューワーへ停止要求を送り、このコマンド自身は
  直ちに終了します。常駐ビューワーは終了せず、現在の再生を止めて次の再生要求を待機します。
  ビューワーが起動していない場合も成功終了します。
- `--skip-decide`: 起動譜面でDecide画面を表示しません。
- `--skip-result`: 単曲プレイ後にResult画面を表示せず、アプリを終了します。

`-P`はオートプレイと`--skip-decide`をまとめて有効にします。Viewer起動ではSelectを
経由せず、最初の描画からPlay画面へ入ります。起動時間を短くするため、選曲リスト、
Select / Decide / Result skin、skin catalog、システムBGM / SEは初期化しません。
単曲の再生後はResult画面を表示せず、最後のPlay画面を保持したまま次の再生を待機します。
再生中に`-S`を受け取った場合も、現在のPlay画面を保持した同じ待機状態へ戻ります。
従来どおり単曲終了時にプロセスも終了させる場合は、`-P --skip-result`を指定します。編集中の
一時ファイルだけを一時ライブラリDBへ取り込むため、通常のライブラリDB、スコア、リプレイ、
IRには記録しません。新しい`-P`起動時に既存の外部ビューワーがあれば、同じプロセスへ
`Play { path, measure }`を転送して現在の再生を差し替えます。起動した側の短命プロセスは
転送完了後すぐ終了します。既存ビューワーがなければ、そのプロセスが常駐ビューワーになります。
常駐ビューワーが受け取る後続の`Play`は、Play skinの開始時計を継続し、ロード演出、
READYアニメーション、READY SEを再生しません。譜面と音声の再読込完了後、指定小節から
シークしたように再生を差し替えます。初回の`-P`起動では通常の開始・READY演出を表示します。

`[PATH]`だけを指定した通常起動でも、未登録の`.bms` / `.bme` / `.bml` / `.pms` /
`.bmson`を1ファイルだけ通常のライブラリへ取り込んで開始できます。

## 停止通信

BMSエディタはBMZと直接通信する必要はありません。従来のuBMplay連携と同様に、停止時は
`bmz-player.exe -S`を別プロセスとして起動します。`-P`と`-S`の短命プロセスが、実行中
ビューワーへ長さ付きコマンドと受信ACKを使う次のローカルIPCで要求を中継します。

- Windows: 名前付きパイプ `\\.\pipe\bmz-player-viewer-v2`
- macOS / Linux: loopback TCP `127.0.0.1:39077`

受信側はプロセス終了まで接続待ちを繰り返し、`Play { path, measure }`と`Stop`を処理します。
`Stop`は常駐プロセスを終了せず、再生状態を破棄して無音の待機状態へ戻します。
`path`は送信側で絶対パスへ解決するため、エディタと常駐ビューワーの作業ディレクトリが
異なっていても同じ一時ファイルを開けます。

## エディタ別設定

| エディタ | 再生設定 | 停止設定 | 備考 |
| --- | --- | --- | --- |
| BMSE / iBMSC | ビューワー実行ファイルに`bmz-player.exe`を指定 | 対応する停止操作が`-S`を起動 | uBMplay互換の`-P -N<小節> <一時BMS>`をそのまま受け付けます。 |
| BMS Maker 3 | ファイル名と開始小節の置換項目を使い、`-P -N<小節> "<ファイル名>"`になるよう設定 | 専用の停止引数欄がない版では、新しい`-P`で再生中譜面を差し替えます | 置換項目の表記は利用中のBMS Maker 3の設定画面に従います。 |
| woseq | ビューワー実行ファイルに`bmz-player`を指定 | なし | woseqが生成する`-P -N<小節> _temp.bms`をそのまま解釈します。 |
| BmsONE | 再生引数を`-P -N$(measure) "$(filename)"`に設定 | 停止引数を`-S`に設定 | 一時`.bmson`も直接読み込めます。 |

BMS Maker 3とwoseqはエディタ側に独立した停止コマンドがない構成でも、同一プロセスでの
再生差し替えは動作します。編集途中で明示的に止めたい場合は、ショートカットなどから
`bmz-player.exe -S`を実行してください。

## ドラッグ＆ドロップ

Select画面のBMZウィンドウへ対応譜面をドロップすると、その1ファイルを通常のライブラリへ
取り込み、通常プレイを開始します。Select以外の画面へのドロップは受け付けません。
