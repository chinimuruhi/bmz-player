# BMS作成ツール向けビューワー

BMZ Playerは、BMSE / iBMSC系のuBMplay互換コマンドラインを使って、編集中の譜面を
一時ビューワーとして再生できます。BMS Maker 3、woseq、BmsONEからも同じ入口を
利用できます。

## コマンドライン

```text
bmz-player.exe -P -N12 "C:\path\to\_temp.bms"
bmz-player.exe -S
```

- `-P` / `--viewer-play`: 指定譜面を外部ビューワーモードで開きます。
- `-N<N>` / `-N <N>` / `--start-measure <N>`: 元譜面の0始まりの小節番号から
  再生します。BMSの先頭ノーツ余白をBMZが追加した場合も、元譜面の小節番号を指定します。
- `-S` / `--viewer-stop`: 実行中の外部ビューワーへ停止要求を送り、このコマンド自身は
  直ちに終了します。ビューワーが起動していない場合も成功終了します。
- `--skip-decide`: 起動譜面でDecide画面を表示しません。
- `--skip-result`: 単曲プレイ後にResult画面を表示せず、アプリを終了します。

`-P`はオートプレイと`--skip-decide`をまとめて有効にします。単曲の再生後はResult画面を
表示せず、次の再生または`-S`を待機します。従来どおり単曲終了時にプロセスも終了させる
場合は、`-P --skip-result`を指定します。編集中の
一時ファイルだけを一時ライブラリDBへ取り込むため、通常のライブラリDB、スコア、リプレイ、
IRには記録しません。新しい`-P`起動時には、既存の外部ビューワーへ停止要求を送ってから
新しい譜面を開きます。

`[PATH]`だけを指定した通常起動でも、未登録の`.bms` / `.bme` / `.bml` / `.pms` /
`.bmson`を1ファイルだけ通常のライブラリへ取り込んで開始できます。

## 停止通信

BMSエディタはBMZと直接通信する必要はありません。従来のuBMplay連携と同様に、停止時は
`bmz-player.exe -S`を別プロセスとして起動します。そのプロセスが実行中ビューワーへ次の
ローカルIPCで停止要求を中継します。

- Windows: 名前付きパイプ `\\.\pipe\bmz-player-viewer-v1`
- macOS / Linux: loopback TCP `127.0.0.1:39076`

## エディタ別設定

| エディタ | 再生設定 | 停止設定 | 備考 |
| --- | --- | --- | --- |
| BMSE / iBMSC | ビューワー実行ファイルに`bmz-player.exe`を指定 | 対応する停止操作が`-S`を起動 | uBMplay互換の`-P -N<小節> <一時BMS>`をそのまま受け付けます。 |
| BMS Maker 3 | ファイル名と開始小節の置換項目を使い、`-P -N<小節> "<ファイル名>"`になるよう設定 | 専用の停止引数欄がない版では、新しい`-P`が既存ビューワーを置き換えます | 置換項目の表記は利用中のBMS Maker 3の設定画面に従います。 |
| woseq | ビューワー実行ファイルに`bmz-player`を指定 | なし | woseqが生成する`-P -N<小節> _temp.bms`をそのまま解釈します。 |
| BmsONE | 再生引数を`-P -N$(measure) "$(filename)"`に設定 | 停止引数を`-S`に設定 | 一時`.bmson`も直接読み込めます。 |

BMS Maker 3とwoseqはエディタ側に独立した停止コマンドがない構成でも、新規再生による
置き換えは動作します。編集途中で明示的に止めたい場合は、ショートカットなどから
`bmz-player.exe -S`を実行してください。

## ドラッグ＆ドロップ

Select画面のBMZウィンドウへ対応譜面をドロップすると、その1ファイルを通常のライブラリへ
取り込み、通常プレイを開始します。Select以外の画面へのドロップは受け付けません。
